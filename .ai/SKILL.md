# React Native Project AI Skills

This repository contains AI skills that define how code must be written in this project.

Before implementing any code, the AI agent MUST read and understand the following files:

1. project-architecture.md
2. coding-rules.md
3. component-guidelines.md
4. feature-development-workflow.md
5. api-integration-rules.md

The agent must follow these rules strictly when generating code.

If a request conflicts with these rules, the agent must explain the conflict and propose a compliant solution.
